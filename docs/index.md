# Crosswork CNC Hands-on

This is the operator lab for Cisco Crosswork Network Controller (CNC) 7.2.1-SP. You will use a dedicated controller and a Cisco Modeling Labs (CML) topology.


## How to read each chapter

Each chapter has an objective, the clicks, the result you should see, and a short "done when" list. Router work in this lab is `show` output. Configuration changes go through CNC, and only in the chapters that say so.

## View this guide

From this folder, with the existing virtual environment:

```bash
source venv/bin/activate
mkdocs serve
```

Open the local URL MkDocs prints. `mkdocs build` writes the static site under `site/`.
