1. Preparation¶

Time: 30 minutes, most of it waiting.

Objective: Leave maintenance mode, start the CML lab, and log in to a controller that is ready for work.

Instructor

One person moves the maintenance slider, and one person starts the CML lab. Ask everyone else to stay logged out until you say the UI is back. Maintenance mode shuts the applications down gracefully, and bringing them back takes several minutes. During that window the UI is the wrong place to click.

1.1 Leave maintenance mode¶

Maintenance mode is how CNC stops itself cleanly for a reboot, a backup, or a restore. After a reboot that began in maintenance mode, the cluster comes back in maintenance mode and waits for the slider to be turned off.

The instructor does this while the room watches the screen:

  1. Sign in to the CNC UI at the URL on the whiteboard.
  2. If the browser reports a certificate warning, check that the hostname matches the whiteboard URL, then use the exception the instructor demonstrates. That exception is for this lab URL.
  3. Go to Administration > Settings > System Settings > Maintenance Mode.
  4. If a popup already offers to turn maintenance mode off, accept it.
  5. If the Maintenance slider is On, drag it to Off and confirm.
  6. If the cluster was rebooted in maintenance mode and you see no popup, turn the slider On, wait until the mode is fully on, then turn it Off again. CNC 7.1 uses that extra toggle to let the applications start cleanly.
  7. Wait. The applications need several minutes. Leave the session alone while they restart.

Result: The maintenance slider stays Off, the UI loads the normal home page, and other users can sign in.

Students sign in only after the instructor confirms that step.

1.2 Start the CML lab¶

The routers, the SR-PCE, and the traffic in this class come from the CML topology named on the whiteboard.

  1. Open the CML URL from the whiteboard.
  2. Open the PTA lab.
  3. If the lab is already started, leave it running.
  4. If the lab is stopped, start it once. A second start from another seat fights the first one.
  5. Wait until every node the instructor listed shows as booted.
  6. Open one provider-edge console only if the instructor asks. Confirm the management interface is up. Save configuration commands for later chapters, and only the ones CNC sends.

Result: The lab is booted. CNC can reach the devices after the providers and the Data Gateway are healthy. You confirm that reachability in the next chapter.

1.3 Sign in and look around¶

  1. Sign in to CNC with the account the instructor gives you.
  2. Land on the home page. You should see the application launcher and a topology entry point.
  3. Open the account menu only far enough to see which user you are. Sign out at the end of the day. Leave the user list unchanged.

Result: You are in the UI as yourself, and the controller is in normal operating mode.

Done when¶

  • Maintenance mode is Off.
  • The CML lab is booted.
  • You are signed in.
  • You have your seat number and the lab-values table from the home page.
